隐私政策

网页预览版本 · 2026.09

01适用范围与处理原则

本说明适用于 ReliaSense iPhone App 和首发计划中的配对 Apple Watch 体验。研发：ReliaSense 团队；上架开发者：任辰昱；实际运营和资料处理责任主体尚待确认。联系邮箱为 reliasense@163.com。App 以设备内处理和本地存储为主；使用 Apple 健康、语音识别、地图、设备同步，或主动发送反馈邮件时，仍可能涉及相应服务的数据处理。“本地为主”不等于所有功能都离线。

本网站当前没有统计脚本、远程字体、表单或自建后端。网站仅在浏览器本地保存你选择的画面动态开关；主动开启倾斜视角时，方向信息只用于当前页面的视觉效果，不保存、不上传。

02网站访问与托管

本站拟由独立的公开 GitHub Pages 网站仓库托管，尚无独立域名；App 源码仓库继续保持私有。浏览本站不会把 App 内健康记录或小世界资料发送给 GitHub。GitHub 官方说明：访问 Pages 站点时，无论是否登录 GitHub，访客 IP 地址都会因安全目的被记录和保存。访问时间、设备及页面使用信息也可能按其隐私声明处理；处理地点可能在中国大陆以外。具体保存期限由 GitHub 规则决定，本站不作代为删除承诺。详见 GitHub Pages 说明和 GitHub 隐私声明。

03健康数据与趋势

经你授权，App 可只读访问 Apple 健康中的心率、心率变异性、睡眠、步数、活动能量、健身时长、饮食咖啡因和经期记录；设备支持时还可读取睡眠手腕温度与环境音暴露，用于展示身体趋势及相关摘要。经期模块只显示是否有记录，不推断其他敏感细节。当前接入不向 Apple 健康写入或删除原始记录。数据来源、佩戴情况和测量时间会影响展示；趋势是日常参考，不用于诊断。

04资料、日常事件和小世界

你填写的个人资料、头像、偏好与草稿，以及主动确认的日常事件、饮用和感受，会用于 App 内的记录与展示。日历功能会读取候选事件的标题、时间等信息；由你确认后，相关内容才形成 App 事件，当前路径不创建、修改或删除系统日历事件。

伙伴外观、物品、作品、共同记忆和场景相册等小世界资料主要保存在 iPhone。当前没有 ReliaSense 云账户或完整云同步；系统备份是否包含具体文件，要以最终发布包和设备设置为准。

05地点与地图

你可保存地点名称、坐标和范围；获相应授权后，App 可使用当前位置及进出地点信息提供地点相关功能。地点资料保存于设备，并不代表地点搜索、地图显示或地址解析完全离线。使用 Apple 地图相关服务时，数据处理也受 Apple 服务规则影响。位置权限可在系统设置中调整，拒绝或撤回后，相关功能可能不可用。

06语音、相机与照片

你主动使用事件语音输入或伙伴语音聊天时，App 录取语音并转写为文字；浏览小世界不会持续开启麦克风。设备支持本机识别时会要求本机处理；不支持时可能使用 Apple 的联网语音识别服务。事件文字须经你确认后才保存；伙伴聊天也可改用文字输入。Apple 服务的数据处理详见 Apple 隐私政策及 中国大陆隐私政策说明。

相机可用于拍摄头像。你选择的图片还可能用于识别、自制食物或反馈附件；这些输入的处理与保存方式各不相同。小世界中主动保存的虚拟场景照片进入 App 本地相册。主动分享到其他 App 或附在邮件中的图片，会由接收方或邮件服务继续处理，不能通过 App 本地重置撤回。

07配对 Apple Watch

首发计划包含配对 Apple Watch。iPhone 会把你已启用的首页模块投影为适合手表显示的摘要，可包含 HRV 趋势、关系状态通用趋势、心率、睡眠、手腕温度、环境音、健身、经期是否有记录及通用休息提示等；不发送原始健康样本、人物关系事件、共同记忆或自由聊天原文。手表上的茶邀请与回应通过配对设备传输。表盘小组件只保留伙伴名称、趋势状态和可见时的 HRV 等更小摘要，并使用隐私遮挡。手表离线时，摘要刷新和删除或重置消息可能延后；过期摘要会显示等待同步，不能保证即时完成。

08反馈邮件

你使用邮件客户端联系支持时，邮件服务可能处理草稿、邮箱地址、正文及你选择的附件；确认发送后，收件方会收到相应内容。App 的本地重置无法删除已经发送的邮件。你可联系 reliasense@163.com 询问支持方实际持有信息的查阅、更正或删除事宜；仅存在于你设备上的资料，支持方无法远程读取或恢复。客服邮件的具体保留安排仍待确认。

09你的选择与删除

你可以在 App“我的 → 隐私与数据 → 重置本地数据”查看提示并确认清理；也可以在 iOS 设置或“健康”App 中撤回健康、日历、位置、麦克风及语音识别等权限。关闭页面展示不等于撤回读取授权。

本地重置会尝试清理 App 的临时输入、事件与反馈草稿及附件、伙伴与小世界资料、饮用记录、场景相册、提醒记录、地点与部分偏好，并向 Watch 发送清除摘要的状态；如果某一步失败，App 会提示重置失败，不能把它当作全部清理成功。本地重置不会删除 Apple 健康原始记录，也不会自动撤销系统权限。再次授权或保留授权后，部分趋势可能重新从原始样本生成。已分享文件、已发送邮件、系统备份及其他服务中的副本需要分别管理。Watch 离线时，配对设备上的清理可能延后。

10保存、安全与更新

设备内资料通常保留到你在 App 中清理、卸载 App，或系统按其规则移除数据；实际备份与恢复还取决于设备和发布包。客服邮件由邮件服务及实际负责支持的主体处理，GitHub Pages 访问记录由 GitHub 按其规则处理。客服邮件等由团队实际持有资料的保留期限尚待确认，本预览不把草案写成已执行的删除制度。

正式政策应在发布前明确运营和资料处理责任主体、适用版本、生效及更新日期、未成年人使用安排，并说明更新时的告知方式。
